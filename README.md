# 🏭 Work Check-In — Терминал учёта сотрудников цеха

Терминал для учёта прихода/ухода сотрудников на производстве с распознаванием лиц,
снимками с камеры, автоматической отправкой отчётов по email и веб-интерфейсом
для мастера цеха.

![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

---

## ✨ Возможности

- 📸 **Снимок с камеры** при каждом приходе/уходе сотрудника
- 🔍 **Распознавание лиц** (опционально) — сотрудник определяется автоматически
- 🖥️ **Сенсорный терминал** — крупные кнопки, виртуальная клавиатура
- ⏱️ **Учёт рабочего времени** — автоматический расчёт отработанных часов
- 📧 **Email-отчёты** — утренний и вечерний отчёт мастеру цеха с фотографиями
- ⚠️ **Контроль «забытых» смен** — если сотрудник не нажал «УШЁЛ» более 15 часов,
  смена закрывается автоматически, а сотрудник попадает в отдельную секцию отчёта
- 💾 **Сохранение состояния** — данные не теряются при перезапуске
- 🌤️ **Погода** — отображение текущей погоды на главном экране
- ⚙️ **Настройки** — SMTP, расписание отправки, параметры распознавания

## 🚀 Быстрый старт

### Требования

- **Python 3.9+**
- **Windows** (используется `tkinter` и работа с камерой)
- Веб-камера (для съёмки сотрудников)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<ваш-логин>/work-check-in.git
cd work-check-in

# 2. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скопировать примеры конфигов и заполнить свои данные
copy settings.example.json settings.json
copy employee_state.example.json employee_state.json

# 5. Запустить
python main.py

# Запуск в Windows
@echo off
call venv\Scripts\activate
python main.py
pause
