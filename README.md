# 🏭 Work Check-In — Терминал учёта сотрудников цеха

Терминал для учёта прихода/ухода сотрудников на производстве с распознаванием лиц,
снимками с камеры, автоматической отправкой отчётов по email и веб-интерфейсом
для мастера цеха.

![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Возможности

- 📸 **Снимок с камеры** при каждом приходе/уходе сотрудника
- 🔍 **Распознавание лиц** (опционально) — сотрудник определяется автоматически
- 🖥️ **Сенсорный терминал** — крупные кнопки, виртуальная клавиатура
- ⏱️ **Учёт рабочего времени** — автоматический расчёт отработанных часов
- 📧 **Email-отчёты** — утренний и вечерний отчёт мастеру цеха с фотографиями
- ⚠️ **Контроль «забытых» смен** — если сотрудник не нажал «УШЁЛ» более 15 часов,
  смена закрывается автоматически, а сотрудник попадает в отдельную секцию отчёта
- 💾 **Сохранение состояния** — данные не теряются при перезапуске
- 🌤️ **Погода** — отображение текущей погоды на главном экране
- 📡 **Передача в систему** — при каждом «пришел/ушел» (и автозакрытии) терминал
  отправляет срез состояния в API системы Русмаш по API-ключу (меню Check-in)
- ⚙️ **Настройки** — SMTP, расписание отправки, параметры распознавания, API

## 🚀 Быстрый старт

### Требования

- **Python 3.9+**
- **Windows** (используется `tkinter` и работа с камерой)
- Веб-камера (для съёмки сотрудников)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/SadovovAlex/work-check-in.git
cd work-check-in

# 2. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скопировать примеры конфигов и заполнить свои данные
copy settings.example.json settings.json
copy employee_state.example.json employee_state.json

# 5. Запустить
python main.py

# Запуск в Windows
@echo off
call venv\Scripts\activate
python main.py
pause

## 📡 Отправка срезов в систему (API)

Терминал при каждом сохранении состояния («пришел», «ушел», автозакрытие смены,
загрузка) отправляет срез `employee_state.json` в систему Русмаш:

```
POST {api_url}          # пример: http://server/api/checkin
X-API-Key: <ключ>       # API-ключ выдаёт админ в меню «Check-in»
```

Настройки в `settings.json` (секция `app_settings`) или в окне настроек
«🌐 ОТПРАВКА В СИСТЕМУ (API)»:

```json
"api_enabled": true,
"api_url": "http://server/api/checkin",
"api_key": "48-символьный ключ из меню Check-in",
"terminal_name": "Терминал 1"
```

- Кнопка **«ОТПРАВИТЬ СРЕЗ СЕЙЧАС»** — ручная проверка связности.
- При недоступности сервера последний срез сохраняется в `api_pending.json`
  и повторяется каждые 30 секунд (планировщик).
- Повторная отправка того же среза безопасна: сервер идемпотентен
  (повторные события не создаются).
- В системе время ЧИС попадает в расчётный лист выработки для сверки
  (менеджер/админ, раздел Check-in → расчётный лист).
- Формат среза и контракт эндпоинта: `docs/API-CHECKIN.md` в системе Русмаш.
